## 7. 오류별 재현 절차

**F-3 favicon 404**
1. `curl -s -o /dev/null -w "%{http_code}" https://utmb2027.vercel.app/favicon.ico` → 404.
2. 브라우저(창 표시)로 아무 화면이나 연 뒤 개발자 도구 Console → "Failed to load resource … 404 … /favicon.ico".

**E-1 응답 지연(TC-P0-04 desktop)**
1. 관리자 세션으로 `/admin/bookings`(1440×900) → "Refuge de la Balme" 편집.
2. 공개 상태 "문의", 비공개 메모 입력 → "저장".
3. 기대: 10초 안에 패널에 `role="status"` "저장됨 · …". 실제: "저장 중…" 약 11.7초 유지 후 표시.

**E-1 응답 지연(TC-P1-05 desktop)**
1. 비로그인으로 `/signup` 접속. 2. JS 청크 응답이 13~27초 걸려 헤더 계정 자리 skeleton이 60초 안에 사라지지 않음.
